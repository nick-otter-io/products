Same readings as the ebook check. People drop capitals, accents, and apostrophes. sao paulo is still São Paulo. macos is still macOS. phuket is still poo-ket. The heading is what you should hear.

A name is the name, not the letters, even when the capital is gone. Ng is a syllable. Siobhan is shi-vawn. Nguyen is ngwen. Xavier is zay-vee-er. Joaquin is wah-keen. Saoirse is seer-sha.

dr. ng reviewed the chart and siobhan walsh signed the letter, nguyen tran booked the flight.

xavier cole arrived at noon, joaquin hale sent the note, saoirse quinn read the poem.

sean obrien paid the bill, mr. watanabe called from osaka, chloe martin left a message.

A foreign place is the place, with or without the marks. Worcestershire is woos-ter-sher. Gloucestershire is glos-ter-sher. Phuket is poo-ket. sao paulo is São Paulo. munchen is München.

the road runs through worcestershire and gloucestershire, the signs are impossible.

phuket is an island and its nice if you ignore the traffic. she flew to sao paulo last march.

the train stops in munchen, or munich, same city. we met in cote divoire and the spelling was all over the thread.

reykjavik is cold in january, the port is in doha, qatar, the cafe is in montreal.

beijing hosted the meeting, the castle is in edinburgh, she lives in los angeles.

A case change stays one token. Lowercase macos is still mac O S. saas is sass. jpeg is jay-peg. ieee is the letter names. LaTeX is lah-tek.

install macos tonight, the product is saas, export one jpeg.

cite the ieee paper and write it in latex, the formatting is a pain.

A brand is the brand. ikea is ee-kay-uh. hyundai is hun-day. nvidia is en-vid-ee-uh. huawei is wah-way. iphone, youtube, ebay, and github stay those names.

ikea opened a store, hyundai posted a recall, nike released the shoe.

the chip is from nvidia and huawei shipped the radio, she drives a toyota, the phone is from samsung.

the clip is on youtube, the phone is an iphone, the listing is on ebay, the repo is on github.

A hyphen or an ampersand splits the token. covid-19 is covid nineteen. at&t is A T and T.

covid-19 spread in march and at&t called at noon, procter & gamble called too.

r&d met at noon and the q&a ran long, as usual.

A code is spoken so it can be typed. utf-8 is U T F 8. A ZIP code is digits.

save the file as utf-8, the build is ios 18, flight ua 418 boards at noon.

the zip code is 94043, the office is in mountain view, CA 94043.

the error is http 404, the gate is b12, the sku is bx-4402, the confirmation code is k7m-22p.

A URL is spoken as an address. A slash inside it is not the word per. An email says at, and dot.

open https://example.com/help today, see https://en.wikipedia.org/wiki/Paris for the map.

the short link is example.com/deals, visit www.example.com/docs, write to ada@example.com.

A path says the word slash between the pieces.

the file is usr/local/bin and the sheet is in reports/2024/q3.pdf, good luck finding it.

C++ is C plus plus. C# is C sharp. .NET is dot net. Lowercase does not change them.

the service is written in c++, the tool ships with c#, the library targets .net.

A formula is letters and numbers. h2o is H 2 O. co2 is C O 2. nacl is N A C L.

water is h2o, air holds co2, the salt is nacl. basic stuff and people still write it messy.

A slash between words is or, except a paired role, which is and.

the result is pass/fail, bring a pen and/or a pencil, she is the writer/director.

A dash in prose is a pause. An ellipsis is a pause. Extra marks do not get read aloud.

the hall — the old one — was shut… and then she left, which tracks.
